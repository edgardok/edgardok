### About me

I run **[Offensive Zone](https://offensive-zone.com)**, a boutique penetration testing and red team practice — web, mobile, network and AWS cloud engagements for companies that want an adversary's perspective on their own systems, not just a checklist. Outside of client work, I contract as **Lead Security Engineer at Qubika**, where I lead a multidisciplinary offensive security team.

I care about pushing secure-by-design practices into engineering workflows, not just finding bugs after the fact — and about building tooling that makes offensive work faster and more repeatable.

- 🔭 Currently building **[offsec-agent](https://github.com/edgardok)** — an offensive security agent where an LLM proposes payloads and deterministic verification confirms validity through signal reproduction and negative controls.
- 🛡️ Bug bounty reports credited by **CERN**, the **U.S. Department of State**, **U.S. HHS**, and multiple **HackerOne** programs.
- 🌎 Based in Argentina · 🗣️ Spanish (native), English (C1) · 👨‍👩‍👧‍👦 Father of two.
- 😄 "Breaking things" for a living.
